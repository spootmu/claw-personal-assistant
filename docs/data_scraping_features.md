# 数据抓取功能说明

## 概述
本项目现已集成高级数据抓取功能，特别针对房产网站如58同城进行了优化。该功能实现了反反爬虫措施，能够在遵守网站服务条款的前提下获取公开信息。

## 核心特性

### 1. 反检测机制
- 用户代理轮换
- 请求频率控制
- 重试逻辑与指数退避
- 验证码/反爬虫页面检测

### 2. 智能调度
- 任务优先级管理
- 失败重试机制
- 依赖关系处理
- 结果持久化

### 3. 58同城专项优化
- 南京地区办公楼销售信息抓取
- 价格筛选功能（默认500万人民币起）
- 结构化数据解析
- 防止重复抓取

## 使用方法

### 直接调用
```python
# 在助手实例中调用
listings = await assistant.scrape_58_tongcheng_data(
    city="nj",        # 南京
    min_price=5000000 # 500万人民币
)
```

### 通过任务调度系统
物业抓取任务已自动注册到智能调度器，将在系统启动5分钟后首次运行，之后可根据需要定期执行。

## 数据处理

### 存储位置
- 结构化数据：`claw_data.db`（SQLite数据库）
- 原始数据：JSON文件（按时间戳命名）
- 学习记录：内存系统和数据库

### 数据格式
每个房源列表包含：
- 标题
- 价格
- 位置
- 面积
- 描述
- 链接
- 抓取时间

## 注意事项

1. **合规使用**：请确保使用符合目标网站的服务条款
2. **频率控制**：系统内置了速率限制以减少对目标服务器的压力
3. **错误处理**：网络异常和反爬虫措施都有相应的处理机制
4. **数据质量**：抓取的数据可能需要进一步清洗和验证

## 扩展性

该架构设计为可扩展，可以轻松添加对其他网站的支持：
1. 创建新的抓取方法
2. 更新数据模型以支持新字段
3. 添加到任务调度系统

## 维护

系统会自动记录所有抓取活动到学习系统中，便于监控和调试。抓取结果也会存储在数据库中供后续分析使用。
